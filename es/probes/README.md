## 三、写下一个探针之前，先读这三条

1. **先假设我的度量错了。** 新数字出来第一件事是验尺子，不是下结论。
   本目录里多次出现「量的是我的转换器，不是数据」（译文分歧 26.1% → 5.5% → 4.9% 全是假的）。
2. **判据调到第三轮就停手**，残差当上界如实报（`docs/PITFALLS.md` A4）。
3. **量准了也不改变要做的事，就别量。** 缺口已知且有界 ⇒ 要么直接修，要么记账。
   把一个小缺口变成一个新的测量项目，是本项目最贵的失败模式。
