# 意大利语约定宪法 + 记账本

> `FRAMEWORK` 五之二要求每个语种有一份自己的约定记录，**边做边写，不要最后补**。
> es 的教训是这些约定散在对话里，回头没人说得清当初为什么那么定。
>
> 本文件两部分：**① 约定**（定了就别再讨论，改要写明推翻理由和日期）
> **② 记账本**（`IT_PLAN` 规矩一：新发现默认进这里，只有「用户会看到错的内容」才允许打断当前阶段）。

---

## 一、约定

| # | 约定 | 定于 | 理由 / 出处 |

| A1 | **主源是英文版切片** `kaikki.org-dictionary-Italian.jsonl`，不是意语版整包 | 2026-08-12（沿用七月建库） | 实测意语版 38 MB 只有 40,090 条意语音标，法语版里的意语有 684,198 条。「做意语就下意语版」是错的直觉 |

| A3 | **释义只保留三语**：中文 + 英文 + 意大利语 | 2026-08-04 用户方针 | 每个维基版只给"自己语言的词"写定义，对外语词只写翻译 |
| A4 | **例句只认 kaikki**，Tatoeba / OPUS 一律排除 | 2026-08-03 用户方针 | 同上 |

| A19 | **出版层要隐藏什么就写 `sense.hidden=1`，证据层 `sense_src` 永不删改** | 2026-08-13 | wiktextract 把「参见/同义词」小节抓成了义项（全库 3 条）。它们在 kaikki 原文里确实是 senses ⇒ 不能从证据层删；但不该给用户看。不删行还有个好处：复刻闸①仍逐条对得上 |
| A34 | **判官只定位，判据设计与最终裁决必须自己来** | 2026-08-14（实测） | 我读 26 条数出 ~8% 真错，两家判官在 92 条上报 1.1% —— `assolutivo`→「作格」（应为通格）、`imenectomia`→「切开术」（应为切除术，且法语源本身写错）判官都判 ok。⇒ **能自己读的就自己读**，把判据外包等于把标准降到判官的水平 |
| A35 | **词典 ≠ 百科**：收词形与词义，不收实体履历 | 2026-08-14 | `Alameda` 该给「西班牙市镇/加州城市」，不该给 Alameda Research 的崩盘经过 —— 后者没有任何维基词典源，只能靠模型编，违反「错比缺更伤权威」 |
| A33 | **闸报红时先分清：是数据错、是断言过期、还是我的尺子错** | 2026-08-13（阶段 3 复跑旧闸，一次遇齐三种） | ①数据错 → 修数据（占位符裁决没撤回、意语证据挂错大小写行）②断言过期 → 换结构性口径（A28）③**尺子错** → `ingest` 用 `w.lower()` 查 dict，拆大小写后指到了错的行，**库是对的**。⚠️ 判断顺序永远是"先假设我的度量错了" |
| A31 | **跨版收词的判据是「收进来有没有内容」，不是「覆盖率」** | 2026-08-13（阶段 3b） | fr 版有 170,968 个我们没有的词形，但实测 **94.1%（160,874 个）既无音标也无录音**，而 fr 的释义按 A3 不收 ⇒ 收进来就是搜得到、点开什么都没有的空壳。两位顾问一致：划词场景下**"未收录"比"空弹窗"诚实**。只收 it 版那 11,921 个（带真释义的） |
| A32 | **负控报错时先回源看输入，别默认是模型的锅** | 2026-08-13（真事故） | 翻译负控 30 条里 2 条模型输出空串，回查发现原文是意语版的占位符 `definizione mancante; se vuoi, aggiungila tu`（"缺定义，欢迎补充"）—— 模型按 prompt 规则拒绝编造，是对的，负控实际 30/30。**顺带逮到 4,031 条占位符被当成释义提升到了出版层**，其中 1,920 条整个义项只有这句话 |
| A30 | **拆行时新行只带词形级的值，词条级的一律不带** | 2026-08-13（阶段 3a） | `Abate` 从 `abate` 拆出来时带 `ipa`/`level`（意语大小写不影响读音、CEFR 是词形级），但 `gender`/`aux`/`conj`/`plural` 一律不带 —— 它们的真值在 `entry`/`sense_tag` 里，复制过来就是第二份真值（A21） |
| A28 | **闸里不许写死行数**（`count(*) == 198049` 这种），一律写成结构性口径 | 2026-08-13（一天栽三次） | 「锚自己上一版」的断言下一阶段一定红，而红的是断言不是数据 —— 人会习惯性地把它改绿，闸就废了。反例：`sense_gloss 一条没动`；正例：`出版层意语释义 ≤ 已裁决的证据行`。⚠️ 唯一例外是**当前阶段刻意不碰的表**，且必须在下一阶段开始时主动改口径 |
| A29 | **每个阶段结束要把之前所有阶段的闸复跑一遍** | 2026-08-13 | 阶段 2 加了 7,902 条义项后，语法层漏了 415 条及物性标签（Q1 跑在它们出现之前）—— 这个缺口**只有复跑旧闸才看得见**。写库脚本因此必须可增量重跑（只插缺的） |
| A25 | **`alt_of` 不是变形，是独立词条** | 2026-08-13（阶段 2a） | 七月 `build.py:390` 是 `form_of or alt_of` 一起丢，后果是 7,028 个词形界面上一条释义都没有、只显示错话「Banca Centrale Europea 的变位形式」。实测两者在**义项级**无交集（0 条同时有），判据干净；但**词形级会重叠**（`leggere` 既是 `leggero` 的阴性复数又是它的异体，全库 25 例） |
| A26 | **关系词条的中文标签用模板确定性生成，模板表经两位顾问审过** | 2026-08-13（阶段 2a） | 30 条模板见 `fixes/recover_alt_of.py`。分歧处的取舍：`apocopic`→「省尾形式」（v4-pro：叫"截尾"会与 `clipping` 的"截短"混）、`misspelling`→「X 的误拼（**非规范写法**）」（不能给错拼异体的正规地位）、`pronunciation spelling`→「读音拼写」。`src` 记 `template` 而不是 `unknown` —— 模板产出证得出来 |
| A27 | **指针类词条要跟随指针把目标词的中文一并显示，但不在库里复制** | 2026-08-13（阶段 2a） | 两位顾问一致：用户查到 `abaca` 时要的就是 `abacà` 的词义，裸指针没用。读取时 join，目标词释义改了自动跟着变 |
| A23 | **过滤只做源头自己的结构判定，自编的文本判据留到「提升到出版层」时才用** | 2026-08-13（阶段 1.5） | 我写的 `plurale di X` 正则能认 2,651 条指针，但反向核对逮到三类假阴性（目标是多词 `plurale di ospedale psichiatrico` / `vedi` 模板 / `per` 模板）。证据层收全 105,474 条，正则以后改好了**不用重灌数据** —— 这就是两层义项存在的理由 |
| A47 | 🔴 **输出有几个字段，控制组就必须有几组判据；大批量前先跑 1% 切片自己读** | 2026-08-15（代价：418 万 tokens 作废 + 用户账户欠费） | ④⑤ 一次调用产出 `i`（对齐下标）与 `zh`（新建义项的中文），我的控制组**只量了 `i`**，而 prompt 缺陷全在 `zh` 的规则里 ⇒ 拿一个对真正会坏的字段完全瞎的绿灯批准了 2,930 批，跑完才第一次读产出。写控制组前先列输出 schema，逐字段问「这一项错了闸会红吗」 |

| A45 | 🔴 **判据不许用形式代理（长/短/多/少），要按义项本身的含义写** | 2026-08-15（用户点名） | 我写「输出对应词，**不是长句翻译**」没说约束作用在哪一段 ⇒ 模型把括号里的区分信息一起删了（`Saint-Léger (Charente).` → 「圣莱热」，十个法国同名市镇中文全一样，坏 1,528 条）。回头量数据，这个代理连自洽都做不到：**七月从英文翻的中位 7 字、我自己的地理模板中位 21 字、我的 prompt 逼出 4 字**，而三者**括号外**都是 4–6 字 —— 真分界是「括号外＝对应词本体 / 括号内＝区分信息，不限长度」。正确写法：「给出这条义项**指的那个东西**在中文里的说法；若同词形另有义项会撞车，**必须**用括号写出区分点」——后半句可由「同词形中文逐字相同」的闸确定性判定 |
