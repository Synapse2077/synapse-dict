# 意大利语约定宪法 + 记账本

> `FRAMEWORK` 五之二要求每个语种有一份自己的约定记录，**边做边写，不要最后补**。
> es 的教训是这些约定散在对话里，回头没人说得清当初为什么那么定。
>
> 本文件两部分：**① 约定**（定了就别再讨论，改要写明推翻理由和日期）
> **② 记账本**（`IT_PLAN` 规矩一：新发现默认进这里，只有「用户会看到错的内容」才允许打断当前阶段）。

## 一、约定

| # | 约定 | 定于 | 理由 / 出处 |
|---|---|---|---|
| A1 | **主源是英文版切片** `kaikki.org-dictionary-Italian.jsonl`，不是意语版整包 | 2026-08-12（沿用七月建库） | 实测意语版 38 MB 只有 40,090 条意语音标，法语版里的意语有 684,198 条。「做意语就下意语版」是错的直觉 |
| A2 | **意语原文释义来自 `itwiktionary`**，与英文版侧义项对齐后并成一条 | 阶段 1.5 定 | 英文版只给英文定义；意语版自己写的释义库里一条都没有 |
| A3 | **释义只保留三语**：中文 + 英文 + 意大利语 | 2026-08-04 用户方针 | 每个维基版只给"自己语言的词"写定义，对外语词只写翻译 |
| A4 | **例句只认 kaikki**，Tatoeba / OPUS 一律排除 | 2026-08-03 用户方针 | 同上 |
| A5 | **音标存裸串**，展示层统一加 `/.../` | 六语种统一 | 改动雷区见 `PITFALLS` |
| A6 | **不用 G2P 重算音标**；判据只能是"回权威源查不到 **且** 违反音系" | 2026-08-12 | es 上 `eigenvector → eixembeɡˈtoɾ` |
| A7 | **不做自动判重合并** | `PLAYBOOK` 5.6 | es 186 条判重里 12.4% 是义项错配，已判定失败 |
| A8 | **行序一次性固化成 `sense` 主键**，之后任何地方不许再用"第几行"引用 | 阶段 0 | es 把 8 万条对齐存成"definition 第几行"，四个脚本重排后 752 万 tokens 作废 |
| A9 | **七月那 11 个直接写库的脚本已冻结**，`legacy_guard` 拦重跑；新写库一律走 `dbtool.session` | 2026-08-12（阶段 -2） | 重放式脚本会静默撤销已完成的修复，es 一天撞见三次 |
| A10 | **`TRACK` 覆盖所有承载值的列**，只有 id/word/word_norm/is_lemma 四个身份列除外 | 2026-08-12（阶段 -2） | 旧版只追 6 列，`definition` 在闸外，而阶段 0/1 动的就是它 |
| A11 | **结构大改前用 `keep-` 前缀的 tag 备份**，该备份永不被保留策略淘汰 | 2026-08-12（阶段 -2） | 里程碑靠文件名豁免，不靠"记得手动留" |
| A15 | **变形层的判据是 `translation == infl`（模板生成的指针文本），不是"有没有 definition"** | 2026-08-12（阶段 0） | 全库 432,512 个无 definition 的行里 432,490 行两者逐字节相同、可安全丢弃；但剩 **22 行不是变形**（`ganga` 恒河 / `sonata da chiesa` 教堂奏鸣曲），按"无 definition 即变形"会把它们的中文释义直接丢掉 |
| A16 | **`sense_gloss.kind` 一律先记 `equivalent`**（en 与 zh 都是）；`definition` 留给阶段 1.5 的意语单语释义 | 2026-08-12（阶段 0） | `kind` 记的是"这条中文从哪种原文翻来"。⚠️ `kind` **不能拿来选标题行**（es 实测被判成 definition 的 56% 本来就 ≤10 字），展示层取最短的那条 |
| A17 | **中文释义的来源写 `unknown`**（`sense_gloss.src`），不猜 | 2026-08-12（阶段 0） | `translation_src` 整列是空的，逐条来源证明不了；证明不了就写 unknown |
| A13 | **音标与录音的跨版主源是法语版**（音标 698,250 / 录音 38,828，各为英文版的 6.3 / 9.6 倍）；释义不收法语 | 2026-08-12（阶段 -1 实测） | 取数表；⚠️ fr 版重音符位置约定不同，合并前必须归一，否则误报 92% 冲突 |
| A14 | **跨版收割一律按 `lang_code` 过滤，不按词形匹配** | 2026-08-12 | es 曾因按词形匹配混进 63 条非西语录音 |
| A12 | **不修 `level`**，改为加客观频次列 `freq_zipf`（wordfreq，离线、同输入同输出） | `SCHEMA` §9.3 | `level` 是全库唯一没有源、也无法回源的字段；es 核心层 A1–B1 里 42.4% 是专名/词缀/缩写 |

**待定（到对应阶段再拍，别提前讨论）**

- 音标记法取宽式还是严式为主、变体怎么排序 → 阶段 4
- 性别冲突信谁（es 的结论是信 kaikki） → 阶段 2 / 4
- 变形层边界划在哪（`levantarsi` 这类自反式算词条还是变形） → 阶段 2
- 真人录音下不下载（URL 先入库是已定的） → 阶段 6

**三条结论**

1. 🔴 **法语版是 it 最大的跨版资产**：音标 698,250 条是英文版的 **6.3 倍**、
   录音 38,828 条是 **9.6 倍**。阶段 4/6 的主源是它，不是意语版。
   ⚠️ `PITFALLS`：fr 版重音符位置约定不同，没归一会误报 92% 冲突。
2. 🔴 **意语原文释义的真实规模是 105,474 条，不是 714,223** —— 后者 85% 是变形指针
   （`plurale di X`）。`IT_PLAN` 阶段 1.5 按 714,223 排的 3–4 天需要重估。
3. 各源与索引页声称的义项数差全部 ≤0.1%，**取数无损**。

**判断错了的一条（如实记）**：我按"录音/词形并集"取了 el + tr（5.2 MB），
实测 el 录音 **0** 条、tr **112** 条，音标各 392 / 64 条 —— 这个理由不成立。
它们真正有的是意语词形（各 15 万+），但 `form_of` 几乎不标（el 只有 45 条指针，
说明该版根本不做变形标注），所以"非指针词形"这个数在它们身上不可信。
留着不删（已落盘、5 MB），阶段 3 收词时再看要不要用，**不再为它们花时间**。
